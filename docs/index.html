Ana ekranı Nuvio'ya ekle

Uygulama açılmadı mı? Adresi kopyala. Nuvio'da Ayarlar → Eklentiler → Eklenti ekle bölümüne yapıştırıp kurulumu tamamla. Adresi yalnızca tarayıcıda açmak eklentiyi kurmaz.

JS kaynak paketin kuruluysa onu yeniden eklemene gerek yok. Bulduğun içeriği açtığında kurulu kaynaklar akışlarını arar. Kaynak deposu kurulumu ile katalog eklentisi kurulumu ayrıdır.

Alternatif arama katalogları
