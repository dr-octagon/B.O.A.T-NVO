
# Nuvio Türkiye

**[Ana ekran ve aramayı Nuvio'ya ekle](https://dr-octagon.github.io/Nuvio/)** — kurulum düğmeleri ve kopyalanabilir adresler. Manifesti tarayıcıda açmak yerine Nuvio'ya eklenti olarak ekleyin.

JS kaynak deposu: `https://raw.githubusercontent.com/dr-octagon/Nuvio/main/manifest.json`

Mac, Android ve Windows'ta arama için **TMDB Türkçe Arama** eklentisini de ekleyin. [Kurulum adresi ve görsel güncellemeleri](TMDB.md).

GitHub kaynak deposundaki sabit kataloglar ana ekranı sağlar. Dinamik TMDB araması ayrı eklenti üzerinden çalışır; bu PC'deki Windows yardımcısı gerektirmez.

Kaynak kodları: [Nuvio-Source](https://github.com/dr-octagon/Nuvio-Source).
